# Pork Quality Meta-Analysis Outputs

This repository is a static GitHub Pages site for the HTML code and model outputs in this folder.

## Files

- `index.html` is the public entry page.
- `A.html`, `Asp.html`, `B.html`, `CL.html`, `CS.html`, `DL.html`, `Glu.html`, `IMF.html`, `L.html`, `LA.html`, `MS.html`, `OA.html`, `PH24.html`, `PH45.html`, and `SF.html` are the individual output pages.
- `.nojekyll` tells GitHub Pages to publish the files exactly as static HTML.

## Publish on GitHub Pages

1. Create a GitHub repository.
2. Upload all files from this folder to the repository root.
3. In GitHub, open `Settings` -> `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select the `main` branch and the repository root, then save.

The site will be available from the GitHub Pages URL shown in the Pages settings.
